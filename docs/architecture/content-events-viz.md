# Content, events, and visualisations

Spool keeps three things separate:

1. Markdown narrative
2. Event sources
3. Visualisation/layout

Articles reference event sources. They do not own them.

Visualisations render projections. They do not own canonical event state.

Models and tools are event sources/sinks. They do not bypass the event system.

This lets the same article use different evidence, the same evidence power different views, and the same visualisation appear in different narratives.
